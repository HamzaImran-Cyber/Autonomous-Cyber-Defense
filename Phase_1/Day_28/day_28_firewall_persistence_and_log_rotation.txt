* Lifecycle Rotation & Copytruncate Action:

       into compressed `.1.gz` archives (`117` bytes and `68` bytes).
    2. The live log files were truncated back to `0` bytes in place, allowing active 
       daemons to continue writing to the exact same file handle without crashing.

5. KEY TAKEAWAYS
------------------------------------------------------------------------------
* RAM-only firewall rules disappear across system reboots unless exported to disk 
  via `iptables-save` / `/etc/iptables/rules.v4`.
* `copytruncate` is critical for security logs because it zeroes out active files 
  without breaking file descriptor locks held by running background daemons.
* Automated log retention (`rotate 7` + `compress`) keeps disk usage predictable 
  while preserving historical telemetry for security audits.
