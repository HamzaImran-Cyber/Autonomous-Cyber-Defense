[Command 1: Updating active_response.sh to continuous event loop]
$ cat << 'EOF' > "$HOME/Autonomous Cyber Defense/Phase_1/Day_27/active_response.sh"
#!/bin/bash
# Autonomous Cyber Defense - Continuous Active Response Daemon
ALERT_FILE="$HOME/Autonomous Cyber Defense/Phase_1/Day_26/nids_alerts.log"
BLOCK_LOG="$HOME/Autonomous Cyber Defense/Phase_1/Day_27/active_response_blocks.log"

if [ ! -f "$ALERT_FILE" ]; then
    ALERT_FILE="$HOME/nids_alerts.log"
fi

echo "[ACD DAEMON] Engine started at $(date)" >> "$BLOCK_LOG"

while true; do
    if [ -f "$ALERT_FILE" ]; then
        for ip in $(awk '/ALERT/ {print $9}' "$ALERT_FILE" 2>/dev/null | sort -u); do
            if [ -n "$ip" ] && [ "$ip" != "Probe" ]; then
                if ! sudo iptables -C INPUT -s "$ip" -j DROP 2>/dev/null; then
                    echo "[DAEMON ACTION] Applying firewall block for IP: $ip at $(date +\%T)" >> "$BLOCK_LOG"
                    sudo iptables -A INPUT -s "$ip" -j DROP
                fi
            fi
        done
    fi
    sleep 5
done
EOF
$ chmod +x "$HOME/Autonomous Cyber Defense/Phase_1/Day_27/active_response.sh"

[Command 2: Creating acd-response.service unit configuration]
$ sudo tee /etc/systemd/system/acd-response.service > /dev/null << EOF
[Unit]
Description=Autonomous Cyber Defense Active Response Daemon
After=network.target

[Service]
Type=simple
User=hamzaimran
ExecStart=/bin/bash "/home/hamzaimran/Autonomous Cyber Defense/Phase_1/Day_27/active_response.sh"
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

4. PRACTICAL ANALYSIS & OBSERVATIONS
------------------------------------------------------------------------------
* Systemd Service Unit Lifecycle:
  - Executing `systemctl enable` linked `acd-response.service` to `multi-user.target.wants`, 
    ensuring auto-start upon OS initialization.
  - The process runs persistently in the background under PID `1127`, spawning low-overhead 
    `sleep 5` cycles (PID `1157`).

* Runtime Overhead & Resilience:
  - Memory consumption is capped at ~18.3 MB, maintaining minimal CPU impact (479 ms total).
  - `Restart=always` enforces automatic process recovery within 3 seconds if the daemon 
    is killed or encounters a critical crash.
  - `iptables -C` checks current netfilter state before applying rules, preventing duplicate 
    firewall entry bloat.

5. KEY TAKEAWAYS
------------------------------------------------------------------------------
* Security automation tools must run as system-managed daemons rather than foreground 
  terminal commands to maintain 24/7 active response capability.
* `systemd` handles lifecycle controls, boot-time execution, logging aggregation, and 
  process self-healing automatically.
* Idempotent checks inside background loops ensure system state integrity during repeated 
  monitoring intervals.
