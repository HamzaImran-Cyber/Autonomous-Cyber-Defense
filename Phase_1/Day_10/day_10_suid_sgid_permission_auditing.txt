4. ARCHITECTURAL REAL-WORLD APPLICATION & PROBLEM SOLVING
------------------------------------------------------------------------------
[Audit Target 1: SUID Executables (`-perm -4000`)]
* Purpose: Lists files configured to run with the permissions of the file owner (root) rather than the user running them.
* Security Risk: If an unapproved binary (like a custom script or shell) is given SUID permissions, an attacker can exploit it to instantly gain root control.
* Practical Action: Validated that all active SUID binaries are legitimate OS administration tools (`passwd`, `sudo`, `mount`).

[Audit Target 2: SGID Executables (`-perm -2000`)]
* Purpose: Lists files configured to run with the permissions of the assigned group rather than the user running them.
* Security Risk: Misconfigured SGID files can allow users to alter shared system files or read restricted group logs.
* Practical Action: Confirmed that listed SGID binaries (`crontab`, `chage`, `ssh-agent`) are limited to system account management and authentication processes.

[Audit Target 3: World-Writable Directory Check (`! -perm -1000`)]
* Purpose: Scans for shared folders where anyone can write files, but checks if the sticky bit protection is missing.
* Security Risk: Shared directories without sticky bits allow any user to delete or overwrite files created by other users or the root account.
* Practical Action: Native Linux system paths (`/tmp`, `/var/tmp`) passed cleanly. `/mnt/c` appeared only because it bridges to the external Windows C: drive file system.

5. KEY TECHNICAL LESSONS
------------------------------------------------------------------------------
* Using `-xdev` isolates the search to the Linux file system, preventing `find` from wasting system resources scanning mounted Windows drives (`/mnt/c`).
* SUID (`4000`) and SGID (`2000`) are necessary for tools like `passwd` (which updates `/etc/shadow`), but auditing them periodically ensures no malicious binaries are left behind.
* The sticky bit (`1000`) acts as a critical safety lock on shared folders, ensuring users can only delete files they personal own.
