4. ARCHITECTURAL REAL-WORLD APPLICATION & PROBLEM SOLVING
------------------------------------------------------------------------------
[Parameter Target 1: IP Forwarding (`net.ipv4.ip_forward = 0`)]
* Purpose: Restricts the Linux kernel from acting as a network router between interfaces.
* Security Risk: Enabled IP forwarding allows attackers on compromised subnet segments to route unauthorized traffic through your system.
* Practical Action: Verifying `0` guarantees host isolation and prevents lateral movement bridging within virtual hypervisor switches.

[Parameter Target 2: TCP SYN Flood Protection (`net.ipv4.tcp_syncookies = 1`)]
* Purpose: Enables cryptographic SYN cookies when the kernel's TCP connection backlog queue fills up.
* Security Risk: High-volume SYN flood DoS attacks exhaust RAM connection tables, dropping legitimate incoming traffic.
* Practical Action: Setting `1` allows the system to remain responsive during transport-layer Denial-of-Service attacks.

[Parameter Target 3: ICMP Redirect Dropping (`accept_redirects = 0`)]
* Purpose: Ignores ICMP redirect messages sent by network routers.
* Security Risk: Malicious nodes can send forged ICMP redirect packets to alter system routing tables dynamically (Man-in-the-Middle positioning).
* Practical Action: Disabling redirects forces reliance strictly on static local routing definitions.

[Parameter Target 4: Reverse Path Filtering (`rp_filter = 2`)]
* Purpose: Enables loose Reverse Path Validation according to RFC 3704.
* Security Risk: IP spoofing attacks mask packet origins to bypass access control lists.
* Practical Action: Mode `2` verifies that incoming packets have a reachable route in the local routing table, dropping spoofed packets from unroutable sources.

5. KEY TECHNICAL LESSONS
------------------------------------------------------------------------------
* `/proc/sys/` provides direct access to kernel memory variables exposed as standard text files.
* `sysctl -a` queries active runtime memory configurations without needing to restart services or reboot.
* Ubuntu's default kernel baseline enforces strict low-level protections (`tcp_syncookies=1`, `ip_forward=0`, `accept_redirects=0`), aligning with baseline hardening frameworks.
