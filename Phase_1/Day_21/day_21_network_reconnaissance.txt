5. WHAT I LEARNED TODAY
------------------------------------------------------------------------------
* Active port scanning (`nmap`) tests network accessibility from the outside, 
  while process auditing (`lsof`) reveals exactly which internal binary owns 
  each open socket.
* Service version detection (`-sV`) is essential for vulnerability management 
  because it exposes exact software versions to potential attackers.
* Combining `lsof` with `nmap` provides a complete view of open ports and 
  running services.
