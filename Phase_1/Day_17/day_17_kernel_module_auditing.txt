4. ARCHITECTURAL REAL-WORLD APPLICATION & PROBLEM SOLVING
------------------------------------------------------------------------------
[Audit Target 1: Active Kernel Space (`lsmod`)]
* Purpose: Evaluate what driver code is loaded directly in Ring 0 privilege space.
* Security Risk: Malicious or buggy drivers running in kernel space can compromise system memory completely.
* Practical Action: Output demonstrates that kernel memory is cleanly dominated by active firewall filtering modules (`nft_compat`, `xt_conntrack`, `ip6t_REJECT`) driving your UFW ruleset.

[Audit Target 2: Dynamic Driver Probe (`modprobe -n -v cramfs`)]
* Purpose: Determine if obsolete filesystems can be dynamically inserted into the live kernel.
* Security Risk: Legacy filesystems (like Compressed ROM File System - `cramfs`) lack modern security bounds and are frequent targets for local privilege escalation exploits.
* Practical Action: `modprobe` confirmed `cramfs` is available and loadable on demand (`insmod .../cramfs.ko`), flagging it for CIS hardening via `/bin/true` execution overrides.

[Audit Target 3: Blacklist Auditing (`/etc/modprobe.d/*.conf`)]
* Purpose: Inspect pre-configured kernel driver bans.
* Security Risk: Unrestricted driver loading allows attacker-controlled USB or virtual storage devices to invoke unpatched kernel drivers.
* Practical Action: Default Ubuntu configurations block legacy FireWire and framebuffer drivers, but lack strict CIS execution bans for uncommon filesystems and legacy protocols.

5. KEY TECHNICAL LESSONS
------------------------------------------------------------------------------
* Kernel drivers run with maximum hardware privilege (Ring 0); disabling unneeded drivers eliminates potential kernel exploit paths.
* A standard `blacklist` entry stops auto-probing on boot, but `install <module> /bin/true` is required to completely block manual or service-requested loading.
* Auditing module paths before deploying hardening rules ensures you don't break dependencies used by active security systems like UFW or AppArmor.
