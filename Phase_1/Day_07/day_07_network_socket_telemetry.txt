4. ARCHITECTURAL REAL-WORLD APPLICATION & PROBLEM SOLVING
------------------------------------------------------------------------------
[Audit Target 1: Listening Socket Telemetry (`ss -tulpn`)]
* Purpose: Identifying active network listeners, transport protocols (TCP/UDP), bound local IP addresses, and process owners.
* Security/System Risk: Unrecognized daemons opening wildcard network sockets (`0.0.0.0:*` or `*:*`) expose internal systems to remote unauthorized access.
* Practical Action: Verifying that all open sockets are bound exclusively to internal loopback addresses (`127.0.0.53`, `127.0.0.1`) ensures zero public network attack exposure.

[Audit Target 2: Socket File Descriptor Mapping (`lsof -i`)]
* Purpose: Mapping active sockets back to Linux process binaries, system accounts (`systemd-resolve`, `_chrony`), and open file descriptors (FD `16u`, `17u`).
* Security/System Risk: Rogue binaries disguising process names or hooking unprivileged ports to establish hidden backdoors.
* Practical Action: Cross-referencing `ss` data with `lsof` verifies that network communication endpoints belong to legitimate system daemons with proper file descriptor handles.

[Audit Target 3: Layer-2/Layer-3 Neighbor Verification (`ip neighbor`)]
* Purpose: Auditing the Address Resolution Protocol (ARP) table to map the default gateway IP (`172.29.80.1`) to its physical/virtual MAC address (`00:15:5d:c7:aa:b9`).
* Security/System Risk: Unverified MAC address changes can indicate ARP spoofing or Man-in-the-Middle (MitM) positioning on a local network segment.
* Practical Action: Checking the neighbor cache confirms proper layer-2 gateway resolution within the WSL virtual hypervisor switch.

5. KEY TECHNICAL LESSONS
------------------------------------------------------------------------------
* `systemd-resolved` (PID 93) operates as the local stub resolver, maintaining isolated DNS sockets on loopback endpoints `127.0.0.53:53` and `127.0.0.54:53`.
* `lsof -i -P -n` explicitly links open internet sockets to system user accounts (`systemd-resolve`, `_chrony`) and file descriptor IDs.

* Current system posture maintains zero external network listeners, satisfying baseline attack surface minimization standards.
